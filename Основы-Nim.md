## Проверка установки

Чтобы проверить успешность установки, напишем программу, традиционно используемую в качестве вводного примера: [«Hello World»](https://en.wikipedia.org/wiki/%22Hello,_World!%22_program).

Вывести (т.е. отобразить на экране, а не напечатать на принтере) фразу «Hello World!» в Nim очень просто и не требует какого-либо шаблонного кода.

В новом текстовом файле с именем, например, `helloworld.nim`, нужно написать всего одну строку кода:

`helloworld.nim`

```nim
echo "Hello World!"
```

Фраза, которую вы хотите вывести, должна следовать за командой `echo` и быть заключена в двойные кавычки (").

Сначала нашу программу надо скомпилировать, а затем запустить, чтобы убедиться, что она работает как ожидается.

Откройте терминал в том же каталоге, где находится ваш файл (в Linux можно получить «Открыть терминал здесь», щёлкнув правой кнопкой мыши по каталогу в файловом менеджере; в Windows нужно использовать Shift + правый клик, чтобы получить пункт меню для открытия командной строки).

Компилируем программу, набрав в терминале:

```
nim c helloworld.nim
```

После успешной компиляции программу можно запустить. В Linux — `./helloworld`, в Windows — `helloworld.exe`.

Существует также возможность скомпилировать и запустить программу одной командой. Нужно набрать:

```
nim c -r helloworld.nim
```

`c` указывает Nim скомпилировать файл, а `-r` — немедленно его запустить. Чтобы увидеть все параметры компилятора, введите `nim --help` в терминале.

Если вы используете VSCode с упомянутым расширением Code Runner, просто нажмите Ctrl+Alt+N, и ваш файл будет скомпилирован и запущен.

Каким бы способом вы ни воспользовались, через мгновение в окне вывода (или в терминале) вы должны увидеть:

```
Hello World!
```

Поздравляем, вы успешно запустили свою первую программу на Nim!

Теперь вы знаете, как выводить текст на экран (команда `echo`), компилировать программу (`nim c programName.nim`) и запускать её (различные способы).

Теперь можно приступить к изучению базовых элементов, которые помогут нам писать простые программы на Nim.

## Именование значений

Часто бывает удобно давать значениям в программах имена, чтобы следить за ними. Если мы спрашиваем у пользователя его имя, мы хотим сохранить его для дальнейшего использования, не запрашивая снова и снова каждый раз, когда нужно выполнить вычисление.

В примере `pi = 3.14` имя `pi` связано со значением `3.14`. Исходя из опыта, мы можем сказать, что тип переменной `pi` — (десятичное) число.

Другой пример: `firstName = "Alice"`, где `firstName` — имя переменной со значением `"Alice"`. Мы бы сказали, что тип этой переменной — слово.

В языках программирования это работает аналогично. У таких именованных присваиваний есть имя, значение и тип.

### Объявление переменных

Nim — [статически типизированный](https://en.wikipedia.org/wiki/Type_system#STATIC) язык, а это означает, что тип присваивания должен быть объявлен до использования значения.

В Nim также различают значения, которые могут изменяться (мутировать), и те, которые не могут, но об этом позже. Мы можем объявить переменную (изменяемое присваивание) с помощью ключевого слова `var`, просто указав её имя и тип (значение можно добавить позже), используя синтаксис:

```
var <имя>: <тип>
```

Если значение уже известно, можно объявить переменную и сразу присвоить ей значение:

```
var <имя>: <тип> = <значение>
```

Угловые скобки (`< >`) используются для обозначения того, что вы можете изменить. Так `<имя>` — это не буквально слово «имя» в угловых скобках, а любое имя.

В Nim также есть возможность [вывода типов](https://en.wikipedia.org/wiki/Type_inference): компилятор может автоматически определить тип именованного присваивания по его значению, без явного указания типа.

Поэтому мы можем объявить переменную без явного типа так:

```
var <имя> = <значение>
```

Пример на Nim:

```nim
var a: int  # ①
var b = 7   # ②
```

① Переменная `a` имеет тип `int` (целое число) без явно заданного значения.
② Переменная `b` имеет значение 7, её тип автоматически определяется как `int`.

При именовании важно выбирать осмысленные имена для вашей программы. Имена вроде `a`, `b`, `c` быстро запутывают. Пробелы в имени использовать нельзя, так как это разбило бы его на два. Если выбранное имя состоит более чем из одного слова, обычно используется стиль camelCase (первая буква имени должна быть строчной).

Обратите внимание: Nim не чувствителен к регистру и знакам подчёркивания, т.е. `helloWorld` и `hello_world` — одно и то же имя. Исключение составляет первый символ, который чувствителен к регистру. Имена могут также включать цифры и другие символы UTF-8, даже эмодзи, если пожелаете, но помните, что вам и, возможно, другим придётся их набирать.

Вместо того чтобы писать `var` для каждой переменной, несколько переменных (не обязательно одного типа) можно объявить в одном блоке `var`. В Nim блоками называются части кода с одинаковым отступом (одинаковым количеством пробелов перед первым символом), по умолчанию уровень отступа — два пробела. Такие блоки вы будете видеть повсюду в программах на Nim, не только при присваивании имён.

```nim
var
  c = -11
  d = "Hello"
  e = '!'
```

В Nim использование табуляции для отступов не допускается. Вы можете настроить свой редактор так, чтобы нажатие Tab преобразовывалось в любое количество пробелов. В VS Code по умолчанию Tab равен четырём пробелам. Это легко переопределить в настройках (Ctrl+,), установив `"editor.tabSize": 2`.

Как уже упоминалось, переменные изменяемы, т.е. их значение может меняться (многократно), но их тип должен оставаться тем же, что и при объявлении.

```nim
var f = 7   # ①
f = -3      # ②
f = 19
f = "Hello" # ошибка ③④
```

① Переменная `f` имеет начальное значение 7, её тип выведен как `int`.
② Значение `f` сначала меняется на -3, затем на 19. Оба — целые числа, как и исходное значение.
③ Попытка изменить значение `f` на `"Hello"` вызывает ошибку, потому что `Hello` — не число, и это изменило бы тип `f` с целого числа на строку.
④ `# ошибка` — это комментарий. Комментарии в коде Nim пишутся после символа `#`. Всё, что находится после него на той же строке, будет проигнорировано.

### Неизменяемое присваивание

В отличие от переменных, объявляемых с помощью `var`, в Nim существуют ещё два типа присваивания, значения которых не могут изменяться: одно объявляется ключевым словом `const`, другое — `let`.

#### Const

Значение неизменяемого присваивания, объявленного с помощью `const`, должно быть известно во время компиляции (до запуска программы).

Например, мы можем объявить ускорение свободного падения как `const g = 9.81` или число пи как `const pi = 3.14`, так как их значения известны заранее и не изменятся во время выполнения программы.

```nim
var h = 99
const
  g = 9.81
  i = h + 7 # ошибка ①
```

① Значение константы не может быть изменено. Переменная `h` не вычисляется на этапе компиляции (это переменная, и её значение может меняться во время выполнения программы), следовательно, значение константы `i` не может быть известно на этапе компиляции, что вызовет ошибку.

В некоторых языках программирования принято писать имена констант ЗАГЛАВНЫМИ_БУКВАМИ. В Nim константы пишутся так же, как и любые другие переменные.

#### Let

Неизменяемые присваивания, объявленные с помощью `let`, не обязаны быть известны во время компиляции; их значение можно установить в любой момент выполнения программы, но после установки оно не может быть изменено.

```nim
let j = 35
j = -27   # ошибка ①
var k = -5
let l = k + 7  # ②
```

① Значение неизменяемой переменной не может быть изменено.
② В отличие от примера с `const` выше, это работает.

На практике вы будете встречать и использовать `let` чаще, чем `const`.

Хотя можно использовать `var` для всего, по умолчанию следует выбирать `let`. Используйте `var` только для переменных, которые будут изменяться.

## Базовые типы данных

### Целые числа

Как мы видели в предыдущей главе, целые числа — это числа, записанные без дробной части и без десятичной точки.

Например: `32`, `-174`, `0`, `10_000_000` — всё это целые числа. Обратите внимание, что мы можем использовать `_` в качестве разделителя тысяч, чтобы большие числа были более читаемыми (легче понять, что речь идёт о 10 миллионах, когда написано `10_000_000`, а не `10000000`).

Обычные математические операторы — сложение (`+`), вычитание (`-`), умножение (`*`) и деление (`/`) — работают как обычно. Первые три операции всегда дают целые числа, а деление двух целых чисел всегда даёт число с плавающей точкой (число с десятичной точкой), даже если числа делятся без остатка.

Целочисленное деление (деление с отбрасыванием дробной части) можно выполнить с помощью оператора `div`. Оператор `mod` используется, если нужно получить остаток (модуль) от целочисленного деления. Результатом этих двух операций всегда является целое число.

`integers.nim`

```nim
let
  a = 11
  b = 4

echo "a + b = ", a + b   # ①
echo "a - b = ", a - b
echo "a * b = ", a * b
echo "a / b = ", a / b
echo "a div b = ", a div b
echo "a mod b = ", a mod b
```

① Команда `echo` выведет на экран всё, что следует за ней через запятую. В данном случае она сначала выводит строку `a + b = `, а затем, в той же строке, результат выражения `a + b`.

Вывод должен быть таким:

```
a + b = 15
a - b = 7
a * b = 44
a / b = 2.75
a div b = 2
a mod b = 3
```

### Числа с плавающей точкой

Числа с плавающей точкой, или просто `float`, — это [приблизительное представление](https://en.wikipedia.org/wiki/Floating-point_arithmetic) действительных чисел.

Например: `2.73`, `-3.14`, `5.0`, `4e7` — это float. Обратите внимание, что для больших чисел можно использовать экспоненциальную запись, где число после `e` — показатель степени. В этом примере `4e7` означает \(4 \times 10^7\).

Четыре основные арифметические операции можно применять и к двум float. Операторы `div` и `mod` для float не определены.

`floats.nim`

```nim
let
  c = 6.75
  d = 2.25

echo "c + d = ", c + d
echo "c - d = ", c - d
echo "c * d = ", c * d
echo "c / d = ", c / d
```

Вывод:

```
c + d = 9.0
c - d = 4.5
c * d = 15.1875
c / d = 3.0
```

① Обратите внимание, что в примерах сложения и деления, хотя мы получили число без десятичной части, результат всё равно имеет тип float.

Приоритет математических операций ожидаемый: умножение и деление имеют более высокий приоритет, чем сложение и вычитание.

### Преобразование float и int

Математические операции между переменными разных числовых типов в Nim невозможны и вызовут ошибку:

```nim
let e = 5
let f = 23.456
echo e + f  # ошибка
```

Значения переменных нужно привести к одному типу. Преобразование простое: для преобразования в целое число используется функция `int`, а для преобразования в float — функция `float`.

```nim
let e = 5
let f = 23.987
echo float(e)      # ①
echo int(f)        # ②
echo float(e) + f  # ③
echo e + int(f)    # ④
```

① Вывод float-версии целого `e` (сам `e` остаётся целым).
② Вывод int-версии float `f`.
③ Оба операнда — float, их можно сложить.
④ Оба операнда — целые числа, их можно сложить.

Вывод:

```
5.0
23
28.987
28
```

При использовании функции `int` для преобразования float в целое округление не производится. Дробная часть просто отбрасывается. Для округления нужно вызывать другую функцию, но для этого нам потребуется узнать немного больше об использовании Nim.

### Символы

Тип `char` используется для представления одного [ASCII-символа](https://en.wikipedia.org/wiki/ASCII).

Символы записываются между двумя одинарными кавычками (`'`). Это могут быть буквы, знаки или одиночные цифры. Несколько цифр или несколько букв вызовут ошибку.

```nim
let
  h = 'z'
  i = '+'
  j = '2'
  k = '35'   # ошибка
  l = 'xy'   # ошибка
```

### Строки

Строки можно описать как последовательность символов. Их содержимое записывается между двумя двойными кавычками (`"`).

Можно думать о строках как о словах, но они могут содержать больше одного слова, различные символы или цифры.

`strings.nim`

```nim
let
  m = "word"
  n = "A sentence with interpunction."
  o = ""      # ①
  p = "32"    # ②
  q = "!"     # ③
```

① Пустая строка.
② Это не число (`int`). Так как оно в двойных кавычках — это строка.
③ Хотя это всего один символ, это не `char`, потому что заключено в двойные кавычки.

### Специальные символы

Если попытаться вывести следующую строку:

```nim
echo "some\nim\tips"
```

результат может удивить:

```
some
im    ips
```

Это потому, что некоторые символы имеют специальное значение. Они задаются с помощью экранирующего символа `\`, стоящего перед ними.

- `\n` — символ новой строки
- `\t` — символ табуляции
- `\\` — обратная косая черта (поскольку один `\` используется как экранирующий символ)

Если мы хотим вывести этот пример так, как он написан, есть два варианта:

- Использовать `\\` вместо `\`, или
- Использовать «сырые» строки с синтаксисом `r"..."` (буква `r` непосредственно перед первой кавычкой), в которых нет экранирующих символов: всё выводится как есть.

```nim
echo "some\\nim\\tips"
echo r"some\nim\tips"
```

Вывод:

```
some\nim\tips
some\nim\tips
```

Существуют и другие специальные символы, помимо перечисленных, все они описаны в [руководстве по Nim](https://nim-lang.org/docs/manual.html#lexical-analysis-string-literals).

### Конкатенация строк

Строки в Nim изменяемы, т.е. их содержимое можно изменять. С помощью процедуры `add` можно добавить (присоединить) другую строку или `char` к существующей строке. Если мы не хотим изменять исходную строку, можно также конкатенировать (объединять) строки с помощью оператора `&` — это возвращает новую строку.

`stringConcat.nim`

```nim
var
  p = "abc"   # ①
  q = "xy"
  r = 'z'

p.add("def")   # ②
echo "p is now: ", p

q.add(r)       # ③
echo "q is now: ", q

echo "concat: ", p & q  # ④

echo "p is still: ", p
echo "q is still: ", q
```

① Если мы планируем изменять строки, их следует объявлять как `var`.
② Добавление другой строки изменяет существующую строку `p` на месте, меняя её значение.
③ Можно также добавить `char` к строке.
④ Конкатенация двух строк создаёт новую строку, не изменяя исходные.

Вывод:

```
p is now: abcdef
q is now: xyz
concat: abcdefxyz
p is still: abcdef
q is still: xyz
```

### Логический тип

Логический тип данных (или `bool`) может принимать только два значения: `true` или `false`. Булевы значения обычно используются для управления потоком выполнения (см. следующую главу) и часто являются результатом операторов отношения.

Принято именовать булевы переменные как простые вопросы «да/нет», например: `isEmpty`, `isFinished`, `isMoving` и т.д.

### Операторы отношения

Операторы отношения проверяют отношение между двумя сущностями, которые должны быть сравнимы.

Для проверки равенства двух значений используется `==` (два знака равенства). Не путайте с `=`, который используется для присваивания, как мы видели ранее.

Вот все операторы отношения, определённые для целых чисел:

`relationalOperators.nim`

```nim
let
  g = 31
  h = 99

echo "g is greater than h: ", g > h
echo "g is smaller than h: ", g < h
echo "g is equal to h: ", g == h
echo "g is not equal to h: ", g != h
echo "g is greater or equal to h: ", g >= h
echo "g is smaller or equal to h: ", g <= h
```

Вывод:

```
g is greater than h: false
g is smaller than h: true
g is equal to h: false
g is not equal to h: true
g is greater or equal to h: false
g is smaller or equal to h: true
```

Можно также сравнивать символы и строки:

```nim
let
  i = 'a'
  j = 'd'
  k = 'z'
echo i < j
echo i < k   # ①

let
  m = "axyb"
  n = "axyz"
  o = "ba"
  p = "ba"
echo m < n   # ②
echo n < o   # ③
echo o < p   # ④
```

① Все заглавные буквы идут перед строчными.
② Сравнение строк происходит посимвольно. Первые три символа одинаковы, а символ `b` меньше символа `z`.
③ Длина строки не имеет значения для сравнения, если их символы не идентичны.
④ Более короткая строка меньше более длинной, если все совпадающие символы одинаковы.

Вывод:

```
true
false
true
true
true
```

### Логические операторы

Логические операторы используются для проверки истинности выражения, состоящего из одного или нескольких булевых значений.

- Логическое `and` возвращает `true`, только если оба операнда `true`.
- Логическое `or` возвращает `true`, если хотя бы один операнд `true`.
- Логическое `xor` возвращает `true`, если один операнд `true`, а другой — нет.

- Логическое `not` отрицает истинность своего операнда: `true` превращается в `false`, и наоборот (это единственный логический оператор, принимающий только один операнд).

`logicalOperators.nim`

```nim
echo "T and T: ", true and true
echo "T and F: ", true and false
echo "F and F: ", false and false
echo "---"
echo "T or T: ", true or true
echo "T or F: ", true or false
echo "F or F: ", false or false
echo "---"
echo "T xor T: ", true xor true
echo "T xor F: ", true xor false
echo "F xor F: ", false xor false
echo "---"
echo "not T: ", not true
echo "not F: ", not false
```

Вывод:

```
T and T: true
T and F: false
F and F: false
---
T or T: true
T or F: true
F or F: false
---
T xor T: false
T xor F: true
F xor F: false
---
not T: false
not F: true
```

Операторы отношения и логические операторы можно комбинировать для формирования более сложных выражений.

Например: `(5 < 7) and (11 + 9 == 32 - 2*6)` превратится в `true and (20 == 20)`, затем в `true and true`, и в итоге даст результат `true`.

## Управляющие конструкции

До сих пор в наших программах каждая строка кода выполнялась в какой-то момент. Управляющие конструкции позволяют нам иметь части кода, которые выполняются только при соблюдении некоторого булева условия.

Если представить нашу программу как дорогу, то управляющие конструкции — это различные ответвления, и мы выбираем путь в зависимости от условия. Например, мы купим яйца, только если их цена ниже определённой. Или: если идёт дождь, мы возьмём зонт, иначе (else) — солнечные очки.

В [псевдокоде](https://en.wikipedia.org/wiki/Pseudocode) эти два примера выглядели бы так:

```
if eggPrice < wantedPrice:
    buyEggs

if isRaining:
    bring umbrella
else:
    bring sunglasses
```

Синтаксис Nim очень похож, как вы увидите ниже.

### Оператор if

Оператор `if`, показанный выше, — это простейший способ ветвления программы.

Синтаксис Nim для написания `if`:

```
if <условие>:           # ①
    <блок с отступом>    # ②
```

① Условие должно быть булева типа: либо булева переменная, либо выражение с операторами отношения и/или логическими операторами.
② Все строки после строки `if`, имеющие отступ в два пробела, образуют один и тот же блок и будут выполнены, только если условие истинно.

Операторы `if` могут быть вложенными, т.е. внутри одного `if`-блока может находиться другой `if`.

```nim
let
  a = 11
  b = 22
  c = 999

if a < b:
  echo "a is smaller than b"
  if 10*a < b:                     # ①
    echo "not only that, a is *much* smaller than b"

if b < c:
  echo "b is smaller than c"
  if 10*b < c:                     # ②
    echo "not only that, b is *much* smaller than c"

if a+b > c:                        # ③
  echo "a and b are larger than c"

if 1 < 100 and 321 > 123:          # ④
  echo "did you know that 1 is smaller than 100?"
  echo "and 321 is larger than 123! wow!"
```

① Первое условие истинно, второе ложно — внутренний `echo` не выполняется.
② Оба условия истинны, и обе строки выводятся.
③ Первое условие ложно — все строки внутри его блока пропускаются, ничего не выводится.
④ Использование логического `and` внутри оператора `if`.

Вывод:

```
a is smaller than b
b is smaller than c
not only that, b is *much* smaller than c
```

### Else

`Else` следует за `if`-блоком и позволяет задать ветвь кода, которая выполнится, когда условие в `if` ложно.

```nim
let
  d = 63
  e = 2.718

if d < 10:
  echo "d is a small number"
else:
  echo "d is a large number"

if e < 10:
  echo "e is a small number"
else:
  echo "e is a large number"
```

Вывод:

```
d is a large number
e is a small number
```

Если нужно выполнить блок, только когда условие ложно, можно просто инвертировать условие с помощью оператора `not`.

### Elif

`Elif` — сокращение от «else if», позволяет объединять несколько `if`-ов в цепочку.

Программа проверяет каждое условие, пока не найдёт истинное. После этого все дальнейшие условия игнорируются.

```nim
let
  f = 3456
  g = 7

if f < 10:
  echo "f is smaller than 10"
elif f < 100:
  echo "f is between 10 and 100"
elif f < 1000:
  echo "f is between 100 and 1000"
else:
  echo "f is larger than 1000"

if g < 1000:
  echo "g is smaller than 1000"
elif g < 100:
  echo "g is smaller than 100"
elif g < 10:
  echo "g is smaller than 10"
```

Вывод:

```
f is larger than 1000
g is smaller than 1000
```

В случае с `g`, хотя `g` удовлетворяет всем трём условиям, выполняется только первая ветвь, а все остальные автоматически пропускаются.

### Case

Оператор `case` — ещё один способ выбрать один из нескольких возможных путей, аналогичный `if` с несколькими `elif`. Однако `case` принимает не несколько булевых условий, а любое значение с различимыми состояниями и путь для каждого возможного значения.

Код, написанный с `if-elif`:

```nim
if x == 5:
  echo "Five!"
elif x == 7:
  echo "Seven!"
elif x == 10:
  echo "Ten!"
else:
  echo "unknown number"
```

можно записать с помощью `case` так:

```nim
case x
of 5:
  echo "Five!"
of 7:
  echo "Seven!"
of 10:
  echo "Ten!"
else:
  echo "unknown number"
```

В отличие от `if`, оператор `case` должен охватывать все возможные случаи. Если какие-то из них не интересны, можно использовать `else: discard`.

`case.nim`

```nim
let h = 'y'
case h
of 'x':
  echo "You've chosen x"
of 'y':
  echo "You've chosen y"
of 'z':
  echo "You've chosen z"
else: discard   # ①
```

① Хотя нас интересуют только три значения `h`, мы должны включить эту строку, чтобы охватить все остальные возможные случаи (все остальные символы). Без неё код не скомпилируется.

Вывод:

```
You've chosen y
```

Можно также использовать несколько значений для каждой ветви, если для более чем одного значения должно выполняться одно и то же действие.

`multipleCase.nim`

```nim
let i = 7

case i
of 0:
  echo "i is zero"
of 1, 3, 5, 7, 9:
  echo "i is odd"
of 2, 4, 6, 8:
  echo "i is even"
else:
  echo "i is too large"
```

Вывод:

```
i is odd
```

## Циклы

Циклы — это ещё одна управляющая конструкция, позволяющая выполнять некоторые части кода многократно.

В этой главе мы познакомимся с двумя видами циклов:

- Цикл `for`: выполняется известное количество раз.
- Цикл `while`: выполняется, пока некоторое условие истинно.

### Цикл for

Синтаксис цикла `for`:

```
for <переменнаяЦикла> in <итерируемыйОбъект>:
    <тело цикла>
```

Традиционно в качестве имени переменной цикла часто используют `i`, но можно использовать любое другое. Эта переменная будет доступна только внутри цикла. После завершения цикла её значение удаляется.

Итерируемый объект — это любой объект, по которому можно итерироваться. Из уже упомянутых типов строки являются итерируемыми. (Другие итерируемые типы будут представлены в следующей главе.)

Все строки в теле цикла выполняются на каждой итерации, что позволяет эффективно писать повторяющиеся части кода.

Если мы хотим итерироваться по диапазону (целых) чисел в Nim, синтаксис для итерируемого: `start .. finish`, где `start` и `finish` — числа. Это позволит пройти по всем числам от `start` до `finish`, включая оба конца. Для стандартного диапазона `start` должен быть меньше `finish`.

Если нужно итерироваться до числа, не включая его, используется `..<`:

```nim
for n in 5 .. 9:    # ①
  echo n

echo ""

for n in 5 ..< 9:   # ②
  echo n
```

① Итерация по диапазону чисел с помощью `..` — оба конца включены.
② Итерация по тому же диапазону с помощью `..<` — идёт до верхней границы, не включая её.

Вывод:

```
5
6
7
8
9

5
6
7
8
```

Если нужно итерироваться по диапазону чисел с шагом, отличным от 1, используется `countup`. В `countup` мы задаём начальное значение, конечное значение (включено в диапазон) и размер шага.

`for2.nim`

```nim
for n in countup(0, 16, 4):   # ①
  echo n
```

① Подсчёт от нуля до 16 с шагом 4. Конец (16) включён в диапазон.

Вывод:

```
0
4
8
12
16
```

Для итерации по диапазону чисел, где начало больше конца, используется аналогичная функция `countdown`. Даже при обратном отсчёте шаг должен быть положительным.

```nim
for n in countdown(4, 0):      # ①
  echo n

echo ""

for n in countdown(-3, -9, 2): # ②
  echo n
```

① Для итерации от большего числа к меньшему нужно использовать `countdown` (оператор `..` можно использовать, только если начальное значение меньше конечного).
② Даже при обратном отсчёте шаг должен быть положительным числом.

Вывод:

```
4
3
2
1
0

-3
-5
-7
-9
```

Поскольку строка — итерируемый объект, мы можем использовать цикл `for` для перебора каждого символа строки (такой вид итерации иногда называют «for-each»).

`for3.nim`

```nim
let word = "alphabet"

for letter in word:
  echo letter
```

Вывод:

```
a
l
p
h
a
b
e
t
```

### Цикл while

Цикл `while` будет выполнять блок кода, пока условие истинно. Когда условие становится ложным, цикл завершается, и программа продолжает выполнение со следующей строки после тела цикла.

```nim
var a = 1

while a*a < 10:   # ①
  echo "a is: ", a
  inc a           # ②

echo "final value of a: ", a
```

① Это условие будет проверяться каждый раз перед входом в новую итерацию цикла и выполнением кода внутри него.
② `inc` используется для увеличения `a` на единицу. Это то же самое, что `a = a + 1` или `a += 1`.

Вывод:

```
a is: 1
a is: 2
a is: 3
final value of a: 4
```

### Break и continue

Оператор `break` используется для преждевременного выхода из цикла, обычно при выполнении некоторого условия.

В следующем примере, если бы не было `if` с `break`, цикл продолжал бы выполняться и выводить `i`, пока `i` не станет 1000. Благодаря `break`, когда `i` становится равно 3, мы немедленно выходим из цикла (перед выводом значения `i`).

`break.nim`

```nim
var i = 1

while i < 1000:
  if i == 3:
    break
  echo i
  inc i
```

Вывод:

```
1
2
```

Оператор `continue` немедленно запускает следующую итерацию цикла, не выполняя оставшиеся строки текущей итерации. Обратите внимание, что 3 и 6 отсутствуют в выводе следующего кода:

`continue.nim`

```nim
for i in 1 .. 8:
  if (i == 3) or (i == 6):
    continue
  echo i
```

Вывод:

```
1
2
4
5
7
8
```

### Упражнения

1. [Гипотеза Коллатца](https://en.wikipedia.org/wiki/Collatz_conjecture) — популярная математическая задача с простыми правилами. Сначала выберите число. Если оно нечётное, умножьте его на три и прибавьте один; если чётное, разделите его на два. Повторяйте эту процедуру, пока не дойдёте до единицы. Например, 5 → нечётное → 3*5+1=16 → чётное → 16/2=8 → чётное → 4 → 2 → 1 → конец!
   Выберите целое число (как изменяемую переменную) и создайте цикл, который будет выводить каждый шаг гипотезы Коллатца. (Подсказка: используйте `div` для деления).

2. Создайте неизменяемую переменную, содержащую ваше полное имя. Напишите цикл `for`, который пройдёт по этой строке и выведет только гласные (a, e, i, o, u). (Подсказка: используйте `case` с несколькими значениями на ветви).

## Контейнеры

Контейнеры — это типы данных, которые содержат коллекцию элементов и позволяют нам обращаться к этим элементам. Обычно контейнер также является итерируемым, то есть мы можем использовать их так же, как использовали строки в главе о циклах.

Например, список покупок — это контейнер продуктов, которые мы хотим купить, а список простых чисел — это контейнер чисел. В псевдокоде:

```
groceryList = [ham, eggs, bread, apples]
primes = [1, 2, 3, 5, 7]
```

### Массивы

Массив — простейший тип контейнера. Массивы однородны, т.е. все элементы в массиве должны иметь один и тот же тип. Массивы также имеют постоянный размер, то есть количество элементов (точнее, количество возможных элементов) должно быть известно во время компиляции. Поэтому мы называем массивы «однородным контейнером постоянной длины».

Тип массива объявляется как `array[<длина>, <тип>]`, где `длина` — это общая вместимость массива (количество элементов, которое он может содержать), а `тип` — тип всех его элементов. Объявление можно опустить, если и длина, и тип могут быть выведены из переданных элементов.

Элементы массива заключаются в квадратные скобки.

```nim
var
  a: array[3, int] = [5, 7, 9]
  b = [5, 7, 9]             # ①
  c = []                     # ошибка ②
  d: array[7, string]        # ③
```

① Если мы предоставляем значения, длина и тип массива `b` известны во время компиляции. Хотя это и правильно, нет необходимости явно объявлять его, как массив `a`.
② Из такого объявления невозможно вывести ни длину, ни тип элементов — это вызывает ошибку.
③ Правильный способ объявить пустой массив (который будет заполнен позже) — указать его длину и тип, не предоставляя значения элементов — массив `d` может содержать семь строк.

Поскольку длина массива должна быть известна во время компиляции, это не сработает:

```nim
const m = 3
let n = 5

var a: array[m, char]
var b: array[n, char]   # ошибка ①
```

① Это вызывает ошибку, потому что `n` объявлен с помощью `let` — его значение не известно во время компиляции. Мы можем использовать только значения, объявленные с `const`, в качестве параметра длины для инициализации массива.

### Последовательности

Последовательности — это контейнеры, похожие на массивы, но их длина не обязана быть известна во время компиляции и может изменяться во время выполнения: мы объявляем только тип содержащихся элементов с помощью `seq[<тип>]`. Последовательности также однородны, т.е. каждый элемент в последовательности должен быть одного типа.

Элементы последовательности заключаются между `@[` и `]`.

```nim
var
  e1: seq[int] = @[]           # ①
  f = @["abc", "def"]          # ②
```

① Тип пустой последовательности должен быть объявлен.
② Тип непустой последовательности может быть выведен. В данном случае это последовательность строк.

Ещё один способ инициализировать пустую последовательность — вызвать процедуру `newSeq`. Мы подробнее рассмотрим вызов процедур в следующей главе, а пока просто знайте, что это тоже возможно:

```nim
var e = newSeq[int]()   # ①
```

① Указание параметра типа внутри квадратных скобок позволяет процедуре узнать, что она должна вернуть последовательность определённого типа. Частая ошибка — пропуск конечных `()`, которые обязательно должны быть включены.

Мы можем добавлять новые элементы в последовательность с помощью процедуры `add`, подобно тому, как мы это делали со строками. Чтобы это работало, последовательность должна быть изменяемой (определена с `var`), а добавляемый элемент должен быть того же типа, что и элементы в последовательности.

`seq.nim`

```nim
var
  g = @['x', 'y']
  h = @['1', '2', '3']

g.add('z')      # ①
echo g

h.add(g)        # ②
echo h
```

① Добавление нового элемента того же типа (`char`).
② Добавление другой последовательности, содержащей тот же тип.

Вывод:

```
@['x', 'y', 'z']
@['1', '2', '3', 'x', 'y', 'z']
```

Попытка передать другие типы в существующие последовательности вызовет ошибку:

```nim
var i = @[9, 8, 7]

i.add(9.81)   # ошибка ①
g.add(i)      # ошибка ②
```

① Попытка добавить float в последовательность int.
② Попытка добавить последовательность int в последовательность char.

Поскольку длина последовательностей может меняться, нам нужен способ узнать их длину. Для этого можно использовать функцию `len`.

```nim
echo g.len
echo h.len
```

Вывод:

```
3
4
```

### Индексация и срезы

Индексация позволяет получить конкретный элемент из контейнера по его индексу. Представляйте индекс как позицию внутри контейнера.

Nim, как и многие другие языки программирования, использует индексацию с нуля, то есть первый элемент в контейнере имеет индекс ноль, второй — индекс один и т.д.

Если нужно индексировать «с конца», используется префикс `^`. Последний элемент (первый с конца) имеет индекс `^1`.

Синтаксис индексации: `<контейнер>[<индекс>]`.

`indexing.nim`

```nim
let j = ['a', 'b', 'c', 'd', 'e']
echo j[1]     # ①
echo j[^1]    # ②
```

① Индексация с нуля: элемент с индексом 1 — это `b`.
② Получение последнего элемента.

Вывод:

```
b
e
```

Срез позволяет получить серию элементов одним вызовом. Используется тот же синтаксис, что и для диапазонов (введённых в разделе о цикле `for`).

Если используется синтаксис `start .. stop`, оба конца включаются в срез. С синтаксисом `start ..< stop` индекс `stop` не включается.

Синтаксис среза: `<контейнер>[<начало> .. <конец>]`.

```nim
echo j[0 .. 3]
echo j[0 ..< 3]
```

Вывод:

```
@['a', 'b', 'c', 'd']
@['a', 'b', 'c']
```

И индексацию, и срезы можно использовать для присваивания новых значений существующим изменяемым контейнерам и строкам.

`assign.nim`

```nim
var
  k: array[5, int]
  l = @['p', 'w', 'r']
  m = "Tom and Jerry"

for i in 0 .. 4:   # ①
  k[i] = 7 * i
echo k

l[1] = 'q'         # ②
echo l

m[8 .. 9] = "Ba"   # ③
echo m
```

① Массив длины 5 имеет индексы от нуля до четырёх. Мы присвоим значение каждому элементу массива.
② Присваивание (изменение) второго элемента (индекс 1) последовательности.
③ Изменение символов строки с индексами 8 и 9.

Вывод:

```
[0, 7, 14, 21, 28]
@['p', 'q', 'r']
Tom and Barry
```

### Кортежи

Оба контейнера, которые мы видели до сих пор, были однородными. Кортежи, с другой стороны, содержат разнородные данные, т.е. элементы кортежа могут быть разных типов. Как и массивы, кортежи имеют фиксированный размер.

Элементы кортежа заключаются в круглые скобки.

`tuples.nim`

```nim
let n = ("Banana", 2, 'c')   # ①
echo n
```

① Кортежи могут содержать поля разных типов. В данном случае: `string`, `int` и `char`.

Вывод:

```
(Field0: "Banana", Field1: 2, Field2: 'c')
```

Мы также можем именовать каждое поле в кортеже, чтобы различать их. Это можно использовать для доступа к элементам кортежа вместо индексации.

```nim
var o = (name: "Banana", weight: 2, rating: 'c')

o[1] = 7          # ①
o.name = "Apple"  # ②
echo o
```

① Изменение значения поля с помощью индекса поля.
② Изменение значения поля с помощью имени поля.

Вывод:

```
(name: "Apple", weight: 7, rating: 'c')
```

## Процедуры

Процедуры, или функции, как их называют в некоторых других языках программирования, — это части кода, выполняющие определённую задачу, упакованные как единое целое. Преимущество группировки кода таким образом в том, что мы можем вызывать эти процедуры вместо того, чтобы писать весь код заново, когда хотим использовать код процедуры.

В некоторых предыдущих главах мы рассматривали гипотезу Коллатца в разных сценариях. Упаковав логику гипотезы Коллатца в процедуру, мы могли бы вызывать один и тот же код для всех упражнений.

До сих пор мы использовали много встроенных процедур, таких как `echo` для вывода, `add` для добавления элементов в последовательность, `inc` для увеличения значения целого числа, `len` для получения длины контейнера и т.д. Теперь мы увидим, как создавать и использовать собственные процедуры.

Некоторые преимущества использования процедур:

- Уменьшение дублирования кода
- Более лёгкое чтение кода, так как мы можем именовать части по тому, что они делают
- Разложение сложной задачи на более простые шаги

Как упоминалось в начале этого раздела, процедуры в других языках часто называют функциями. Это на самом деле не совсем корректно, если рассматривать математическое определение функции. Математические функции принимают набор аргументов (как \(f(x, y)\), где \(f\) — функция, а \(x\) и \(y\) — её аргументы) и всегда возвращают один и тот же ответ для одних и тех же входных данных.

Программные процедуры, с другой стороны, не всегда возвращают одинаковый вывод для заданного ввода. Иногда они не возвращают вообще ничего. Это связано с тем, что наши компьютерные программы могут хранить состояние в переменных, о которых мы говорили ранее, и процедуры могут их читать и изменять. В Nim слово `func` в настоящее время зарезервировано для использования как математически более корректный вид функции, не допускающий побочных эффектов.

### Объявление процедуры

Прежде чем мы сможем использовать (вызвать) нашу процедуру, её нужно создать и определить, что она делает.

Процедура объявляется с помощью ключевого слова `proc`, имени процедуры, за которым следуют входные параметры и их типы в круглых скобках, а последняя часть — двоеточие и тип значения, возвращаемого из процедуры, например:

```
proc <имя>(<p1>: <тип1>, <p2>: <тип2>, ...): <возвращаемыйТип>
```

Тело процедуры записывается в блоке с отступом, следующем за объявлением, к которому добавляется знак `=`.

`callProcs.nim`

```nim
proc findMax(x: int, y: int): int =   # ①
  if x > y:
    return x                          # ②
  else:
    return y
    # это внутри процедуры
# это вне процедуры
```

① Объявление процедуры `findMax`, которая имеет два параметра, `x` и `y`, и возвращает `int`.
② Чтобы вернуть значение из процедуры, используется ключевое слово `return`.

```nim
proc echoLanguageRating(language: string) =   # ①
  case language
  of "Nim", "nim", "NIM":
    echo language, " is the best language!"
  else:
    echo language, " might be a second-best language."
```

① Процедура `echoLanguageRating` просто выводит переданное имя, она ничего не возвращает, поэтому возвращаемый тип не объявляется.

Обычно нам не разрешается изменять переданные параметры. Такой код вызовет ошибку:

```nim
proc changeArgument(argument: int) =
  argument += 5

var ourVariable = 10
changeArgument(ourVariable)
```

Чтобы это работало, нужно разрешить Nim (и программисту, использующему процедуру) изменять аргумент, объявив его как переменную:

```nim
proc changeArgument(argument: var int) =   # ①
  argument += 5

var ourVariable = 10
changeArgument(ourVariable)
echo ourVariable
changeArgument(ourVariable)
echo ourVariable
```

① Обратите внимание: `argument` теперь объявлен как `var int`, а не просто как `int`.

Вывод:

```
15
20
```

Это, конечно, означает, что передаваемое имя также должно быть объявлено как переменная; передача чего-либо, присвоенного с `const` или `let`, вызовет ошибку.

Хотя хорошей практикой является передача значений через аргументы, можно также использовать имена, объявленные вне процедуры, — как переменные, так и константы:

```nim
var x = 100

proc echoX() =
  echo x        # ①
  x += 1        # ②

echoX()
echoX()
```

① Здесь мы обращаемся к внешней переменной `x`.
② Мы также можем обновить её значение, так как она объявлена как переменная.

### Вызов процедур

После того как мы объявили процедуру, мы можем её вызвать. Обычный способ вызова процедур/функций во многих языках программирования — указать её имя и передать аргументы в круглых скобках:

```
<имяПроцедуры>(<арг1>, <арг2>, ...)
```

Результат вызова процедуры можно сохранить в переменной.

Если мы хотим вызвать нашу процедуру `findMax` из примера выше и сохранить возвращаемое значение в переменной, можно сделать так:

`callProcs.nim`
```nim
let
  a = findMax(987, 789)
  b = findMax(123, 321)
  c = findMax(a, b)   # ①

echo a
echo b
echo c
```

① Результат функции `findMax` здесь назван `c` и вызван с результатами первых двух вызовов (`findMax(987, 321)`).

Вывод:

```
987
321
987
```

Nim, в отличие от многих других языков, также поддерживает единый синтаксис вызова функций ([Uniform Function Call Syntax](https://en.wikipedia.org/wiki/Uniform_Function_Call_Syntax)), который допускает множество различных способов вызова процедур.

Вот вызов, где первый аргумент пишется перед именем функции, а остальные параметры указываются в круглых скобках:

```
<арг1>.<имяПроцедуры>(<арг2>, ...)
```

Мы использовали этот синтаксис, когда добавляли элементы в существующую последовательность (`<seq>.add(<element>)`), так как это делает код более читаемым и яснее выражает наше намерение, чем `add(<seq>, <element>)`. Можно также опустить круглые скобки вокруг аргументов:

```
<имяПроцедуры> <арг1>, <арг2>, ...
```

Мы видели этот стиль при вызове процедуры `echo` и при вызове `len` без аргументов. Эти два способа можно также комбинировать, но такой синтаксис встречается нечасто:

```
<арг1>.<имяПроцедуры> <арг2>, <арг3>, ...
```

Единый синтаксис вызова позволяет создавать более читаемые цепочки из нескольких процедур:

```nim
proc plus(x, y: int): int =   # ①
  return x + y

proc multi(x, y: int): int =
  return x * y

let
  a = 2
  b = 3
  c = 4

echo a.plus(b) == plus(a, b)
echo c.multi(a) == multi(c, a)

echo a.plus(b).multi(c)   # ②
echo c.multi(b).plus(a)   # ③
```

① Если несколько параметров имеют одинаковый тип, можно объявить их тип в такой компактной форме.
② Сначала мы складываем `a` и `b`, затем результат этой операции (\(2 + 3 = 5\)) передаётся как первый параметр в процедуру `multi`, где умножается на `c` (\(5 * 4 = 20\)).
③ Сначала мы умножаем `c` и `b`, затем результат (\(4 * 3 = 12\)) передаётся как первый параметр в `plus`, где складывается с `a` (\(12 + 2 = 14\)).

Вывод:

```
true
true
20
14
```

### Переменная result

В Nim каждая процедура, возвращающая значение, имеет неявно объявленную и инициализированную (значением по умолчанию) переменную `result`. Процедура вернёт значение этой переменной `result`, когда достигнет конца своего блока с отступом, даже без оператора `return`.

`result.nim`
```nim
proc findBiggest(a: seq[int]): int =   # ①
  for number in a:
    if number > result:
      result = number
  # здесь конец процедуры ②

let d = @[3, -5, 11, 33, 7, -15]
echo findBiggest(d)
```

① Возвращаемый тип — `int`. Переменная `result` инициализируется значением по умолчанию для `int`: 0.
② Когда достигается конец процедуры, возвращается значение `result`.

Вывод:

```
33
```

Обратите внимание: эта процедура приведена для демонстрации `result` и не является на 100% корректной: если передать последовательность, содержащую только отрицательные числа, процедура вернёт 0 (которого нет в последовательности).

**Осторожно!** В старых версиях Nim (до 0.19.0) значением по умолчанию для строк и последовательностей было [`nil`](https://en.wikipedia.org/wiki/Null_pointer), и при использовании их в качестве возвращаемых типов переменную `result` нужно было инициализировать пустой строкой (`""`) или пустой последовательностью (`@[]`).

```nim
proc keepOdds(a: seq[int]): seq[int] =
  # result = @[]   # ①
  for number in a:
    if number mod 2 == 1:
      result.add(number)

let f = @[1, 6, 4, 43, 57, 34, 98]
echo keepOdds(f)
```

① В Nim версии 0.19.0 и новее эта строка не нужна — последовательности автоматически инициализируются как пустые.
В более старых версиях последовательности нужно инициализировать, и без этой строки компилятор выдал бы ошибку. (Обратите внимание, что `var` использовать не нужно, так как `result` уже объявлен неявно.)

Вывод:

```
@[1, 43, 57]
```

Внутри процедуры можно также вызывать другие процедуры.

`filterOdds.nim`

```nim
proc isDivisibleBy3(x: int): bool =
  return x mod 3 == 0

proc filterMultiplesOf3(a: seq[int]): seq[int] =
  # result = @[]   # ①
  for i in a:
    if i.isDivisibleBy3():   # ②
      result.add(i)

let
  g = @[2, 6, 5, 7, 9, 0, 5, 3]
  h = @[5, 4, 3, 2, 1]
  i = @[626, 45390, 3219, 4210, 4126]

echo filterMultiplesOf3(g)
echo h.filterMultiplesOf3()
echo filterMultiplesOf3 i   # ③
```

① Опять же, эта строка не нужна в новых версиях Nim.
② Вызов ранее объявленной процедуры. Её возвращаемый тип — `bool`, и её можно использовать в операторе `if`.
③ Третий способ вызова процедуры, как мы видели выше.

Вывод:

```
@[6, 9, 0, 3]
@[3]
@[45390, 3219]
```

### Предварительное объявление

Как упоминалось в самом начале раздела, мы можем объявить процедуру без блока кода. Причина в том, что мы должны объявить процедуры до того, как сможем их вызывать; следующий код не сработает:

```nim
echo 5.plus(10)   # ошибка ①

proc plus(x, y: int): int =   # ②
  return x + y
```

① Это вызовет ошибку, так как `plus` ещё не определён.
② Здесь мы определяем `plus`, но так как это после его использования, Nim о нём ещё не знает.

Обойти это можно с помощью так называемого предварительного объявления:

```nim
proc plus(x, y: int): int   # ①

echo 5.plus(10)             # ②

proc plus(x, y: int): int = # ③
  return x + y
```

① Здесь мы сообщаем Nim, что процедура `plus` должна существовать с таким определением.
② Теперь мы свободно можем использовать её в коде, это сработает.
③ Здесь `plus` фактически реализована; это, конечно, должно соответствовать предыдущему определению.

### Упражнения

1. Создайте процедуру, которая будет приветствовать человека (выводить «Hello <имя>») на основе переданного имени. Создайте последовательность имён. Поприветствуйте каждого человека, используя созданную процедуру.
2. Создайте процедуру `findMax3`, которая будет возвращать наибольшее из трёх значений.
3. Точки на 2D-плоскости можно представить как `tuple[x, y: float]`. Напишите процедуру, которая получает две точки и возвращает новую точку, являющуюся суммой этих двух точек (сложите x-ы и y-и по отдельности).
4. Создайте две процедуры `tick` и `tock`, которые выводят слова «tick» и «tock». Заведите глобальную переменную для подсчёта, сколько раз они были выполнены, и запускайте одну из другой, пока счётчик не достигнет 20. Ожидаемый вывод — 20 строк с чередующимися «tick» и «tock». (Подсказка: используйте предварительные объявления.)
   Вы можете нажать Ctrl+C, чтобы остановить выполнение программы, если войдёте в бесконечный цикл.
   Проверьте все процедуры, вызывая их с разными параметрами.

## Модули

До сих пор мы использовали функциональность, доступную по умолчанию при создании нового файла Nim. Её можно расширить с помощью модулей, которые предоставляют дополнительные возможности для определённых задач.

Одни из самых используемых модулей Nim:

- `strutils`: дополнительные функции для работы со строками.
- `sequtils`: дополнительные функции для последовательностей.
- `math`: математические функции (логарифмы, квадратные корни, ...), тригонометрия (sin, cos, ...).
- `times`: измерение времени и работа с ним.

Но их гораздо больше, как в так называемой [стандартной библиотеке](https://nim-lang.org/docs/lib.html), так и в [менеджере пакетов Nimble](https://nimble.directory/).

### Импорт модуля

Если мы хотим импортировать модуль и всю его функциональность, достаточно написать `import <имяМодуля>` в нашем файле. Обычно это делается в начале файла, чтобы сразу было видно, что использует наш код.

`stringutils.nim`

```nim
import strutils   # ①

let
  a = "My string with whitespace."
  b = '!'

echo a.split()            # ②
echo a.toUpperAscii()     # ③
echo b.repeat(5)          # ④
```

① Импорт `strutils`.
② Использование `split` из модуля `strutils`. Разбивает строку на последовательность слов.
③ `toUpperAscii` преобразует все ASCII-буквы в верхний регистр.
④ `repeat` также из модуля `strutils`, повторяет символ или целую строку заданное количество раз.

Вывод:

```
@["My", "string", "with", "whitespace."]
MY STRING WITH WHITESPACE.
!!!!!
```

Для пользователей, пришедших из других языков программирования (особенно Python), способ работы импортов в Nim может показаться «неправильным». Если это так, рекомендуется прочесть [соответствующее обсуждение](https://narimiran.github.io/2019/07/01/nim-import.html).

`maths.nim`

```nim
import math   # ①

let
  c = 30.0     # градусы
  cRadiants = c.degToRad()   # ②

echo cRadiants
echo sin(cRadiants).round(2) # ③
echo 2^15                    # ④
```

① Импорт [`math`](https://nim-lang.org/docs/math.html).
② Преобразование градусов в радианы с помощью `degToRad`.
③ `sin` принимает радианы. Мы округляем (тоже из модуля `math`) результат не более чем до 2 знаков после запятой. (Иначе результат был бы: 0.4999999999999999)
④ Модуль `math` также имеет оператор `^` для вычисления степени числа.

Вывод:

```
0.5235987755982988
0.5
32
```

### Создание собственных модулей

Часто в проекте бывает так много кода, что имеет смысл разбить его на части, каждая из которых выполняет определённую задачу. Если вы создадите два файла рядом в одной папке, назовём их `firstFile.nim` и `secondFile.nim`, вы можете импортировать один из другого как модуль:

`firstFile.nim`

```nim
proc plus*(a, b: int): int =   # ①
  return a + b

proc minus(a, b: int): int =   # ②
  return a - b
```

① Обратите внимание, что у процедуры `plus` после имени стоит звёздочка (`*`); это говорит Nim, что другой файл, импортирующий этот, сможет использовать эту процедуру.
② Напротив, эта процедура не будет видна при импорте этого файла.

`secondFile.nim`

```nim
import firstFile   # ①

echo plus(5, 10)    # ②
echo minus(10, 5)   # ошибка ③
```

① Здесь мы импортируем `firstFile.nim`. Расширение `.nim` указывать не нужно.
② Это сработает и выведет 15, так как процедура объявлена в `firstFile` и видна нам.
③ Однако это вызовет ошибку, так как процедура `minus` не видна из-за отсутствия звёздочки после имени.

Если у вас больше двух файлов, вы можете организовать их в подкаталог (или несколько подкаталогов). При следующей структуре каталогов:

```
.
├── myOtherSubdir
│   ├── fifthFile.nim
│   └── fourthFile.nim
├── mySubdir
│   └── thirdFile.nim
├── firstFile.nim
└── secondFile.nim
```

если вы хотите импортировать все остальные файлы в `secondFile.nim`, это делается так:

`secondFile.nim`

```nim
import firstFile
import mySubdir / thirdFile
import myOtherSubdir / [fourthFile, fifthFile]
```

## Взаимодействие с пользователем

Используя то, что мы изучили до сих пор (базовые типы данных, контейнеры, управляющие конструкции, циклы), мы можем создавать довольно много простых программ.

В этой главе мы научимся делать наши программы более интерактивными. Для этого нам нужна возможность читать данные из файла или запрашивать ввод у пользователя.

### Чтение из файла

Допустим, у нас есть текстовый файл `people.txt` в том же каталоге, что и наш код на Nim. Содержимое этого файла выглядит так:

`people.txt`

```
Alice A.
Bob B.
Carol C.
```

Мы хотим использовать содержимое этого файла в нашей программе как список (последовательность) имён.

`readFromFile.nim`

```nim
import strutils

let contents = readFile("people.txt")   # ①
echo contents

let people = contents.splitLines()      # ②
echo people
```

① Для чтения содержимого файла используется процедура `readFile`, которой передаётся путь к файлу (если файл в том же каталоге, что и программа, достаточно имени файла). Результат — многострочная строка.
② Чтобы разбить многострочную строку на последовательность строк (каждая строка содержит всё содержимое одной строки файла), используется `splitLines` из модуля `strutils`.

Вывод:

```
Alice A.
Bob B.
Carol C.

@["Alice A.", "Bob B.", "Carol C.", ""]
```

① В исходном файле был завершающий перевод строки (пустая последняя строка), который присутствует и здесь.
② Из-за завершающего перевода строки наша последовательность длиннее, чем мы ожидали/хотели.

Чтобы решить проблему с завершающим переводом строки, можно использовать процедуру `strip` из `strutils` после чтения файла. Она просто удаляет так называемые пробельные символы из начала и конца строки. Пробельными символами являются любые символы, создающие пробелы: переводы строк, пробелы, табуляции и т.д.

`readFromFile2.nim`

```nim
import strutils

let contents = readFile("people.txt").strip()   # ①
echo contents

let people = contents.splitLines()
echo people
```

① Использование `strip` даёт ожидаемый результат.

Вывод:

```
Alice A.
Bob B.
Carol C.
@["Alice A.", "Bob B.", "Carol C."]
```

### Чтение пользовательского ввода

Если мы хотим взаимодействовать с пользователем, нужно уметь запрашивать у него ввод, обрабатывать и использовать его. Нам нужно читать из [стандартного потока ввода (stdin)](https://en.wikipedia.org/wiki/Standard_streams#Standard_input_(stdin)), передавая `stdin` процедуре `readLine`.

```nim
echo "Please enter your name:"
let name = readLine(stdin)   # ①

echo "Hello ", name, " nice to meet you!"
```

① Тип `name` выводится как `string`.

Вывод:

```
Please enter your name:
```

① Ожидание ввода пользователя. После того как мы введём имя и нажмём Enter, программа продолжит работу.

```
Please enter your name: Alice
Hello Alice, nice to meet you!
```

**Примечание:** Если вы используете устаревшую версию VS Code, запустить это обычным способом (Ctrl+Alt+N) не получится, потому что окно вывода не поддерживает пользовательский ввод — такие примеры нужно запускать в терминале. В новых версиях VS Code такого ограничения нет.

### Работа с числами

Чтение из файла или пользовательского ввода всегда даёт результат типа `string`. Если мы хотим использовать числа, нужно преобразовать строки в числа: снова используем модуль `strutils` и применяем `parseInt` для преобразования в целые числа или `parseFloat` для преобразования в float.

`interaction2.nim`

```nim
import strutils

echo "Please enter your year of birth:"
let yearOfBirth = readLine(stdin).parseInt()   # ①

let age = 2026 - yearOfBirth

echo "You are ", age, " years old."
```

① Преобразование строки в целое число. В таком виде мы доверяем пользователю ввод корректного целого числа. Что произойдёт, если пользователь введёт '79 или ninety-three? Попробуйте сами.

Вывод:

```
Please enter your year of birth: 1934
You are 84 years old.
```

Если у нас есть файл `numbers.txt` в том же каталоге, что и код, с содержимым:

`numbers.txt`

```
27.3
98.24
11.93
33.67
55.01
```

и мы хотим прочитать этот файл и найти сумму и среднее арифметическое предоставленных чисел, можно сделать так:

`interaction3.nim`

```nim
import strutils, sequtils, math   # ①

let
  strNums = readFile("numbers.txt").strip().splitLines()   # ②
  nums = strNums.map(parseFloat)                            # ③

let
  sumNums = sum(nums)               # ④
  average = sumNums / float(nums.len)   # ⑤

echo sumNums
echo average
```

① Импортируем несколько модулей. `strutils` даёт `strip` и `splitLines`, `sequtils` — `map`, `math` — `sum`.
② Удаляем завершающий перевод строки и разбиваем на строки, создавая последовательность строк.
③ `map` работает, применяя процедуру (в данном случае `parseFloat`) к каждому элементу контейнера. Другими словами, мы преобразуем каждую строку в float, возвращая новую последовательность float.
④ Используем `sum` из модуля `math` для получения суммы всех элементов последовательности.
⑤ Длину последовательности нужно преобразовать в float, потому что `sumNums` — float.

Вывод:

```
226.15
45.23
```

### Упражнения
